# Civic Pollution Reporting App

## 📌 Overview

The Civic Pollution Reporting App is a web application that enables citizens to report pollution-related issues in their locality. Users can submit complaints, upload images, provide locations, and help local authorities identify and resolve environmental problems efficiently.

---

## 🚀 Features

- User Authentication
- Report Pollution Complaints
- Upload Images
- Location-based Reporting
- Dashboard to View Reports
- Complaint Status Tracking
- Responsive User Interface

---

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Parthasarathivm/civic-pollution-reporting-app.git
```

Go to the project

```bash
cd civic-pollution-reporting-app
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:3000
```

## 🎯 Problem Statement

Citizens often face difficulties in reporting pollution issues effectively. This project provides a centralized platform where users can report civic pollution problems with images and location details, enabling faster action by concerned authorities.

---

## 💡 Solution

The application simplifies the complaint submission process through an easy-to-use interface. Reports are stored securely, categorized, and can be monitored through a dashboard, improving communication between citizens and authorities.
